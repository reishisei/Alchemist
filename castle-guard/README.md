# 守墙 · 三路（原型 v0.2）

一个 5 关、单文件、零依赖的网页游戏。双击 `index.html` 就能玩。

v0.2 修了两个东西：**子弹打不中快怪**、**掉元素/合成这条循环没体现**。

---

## 一、你在游戏里做什么

**你不控制攻击。** 角色自动开火。你只做三个决定：

| 决定 | 手段 | 时机 |
|---|---|---|
| 合成什么 | Q 照明弹 / W 焚风 / E 泥沼 | 元素够了，且场上出现了对应的怪 |
| 集火哪一路 | 1 / 2 / 3，A 恢复自动 | 三路同时压下来，你必须选放弃谁 |
| 带多少元素走 | 跨关保留 | 早花 = 轻松，晚花 = 后面没牌 |

---

## 二、元素从哪来（v0.2 的重点）

**杀怪掉元素，掉的是这只怪对应的颜色。**

| 怪 | 掉落 |
|---|---|
| 小兵 兵 | 火 |
| 幻影 影 | 土 |
| 再生 生 | 风 |
| 疾行 疾 | 水 |

- 每只怪死时掉 1 个，飘出 `+火`、`+土` 的字样，右上角计数闪一下
- 每类上限 **4**，满了显示 `满`，不会浪费你的时间
- 每关开始额外补 1 个"本关主题元素"（第 2 关土、第 3 关风、第 4 关水），保证你永远凑得出配方

### 三个融合

| 融合 | 配方 | 效果 | 治谁 |
|---|---|---|---|
| 照明弹 Q | 土 + 火 | 7 秒：幻影实体化，全体受伤 +35% | 幻影（只吃 50% 伤害） |
| 焚风 W | 火 + 风 | 8 秒：禁止回血，每秒 14 灼烧 | 再生（每秒回 7） |
| 泥沼 E | 水 + 土 | 8 秒：移速降到 32% | 疾行（112 速） |

合成要吟唱 **1.2 秒**，期间不能开火——这是"险"的来源。

## 三、城墙怎么掉血（v0.2 改了）

**撞墙即破**：怪走到墙根，立刻扣一个固定值然后消失。

| 怪 | 破墙伤害 |
|---|---|
| 小兵 | 8 |
| 幻影 | 10 |
| 再生 | 6 |
| 疾行 | 12 |

为什么改成这样：原来的"贴墙持续啃"会造成死亡螺旋——三只怪一贴墙，每秒掉十几点，几秒就没了，玩家完全没法反应。现在**每漏一只 = 掉一块**，可数、可解释、不雪崩。

## 四、怪的本质（每种怪 = 一个被推到极端的属性）

| 怪 | 属性 | 基础解（慢但可行） | 元素解（快） |
|---|---|---|---|
| 小兵 | 普通 | 直接打 | — |
| 幻影 | 只吃 50% 伤害 | 硬打 / 蓄力箭 | 照明弹 |
| 再生 | 每秒回 7 | 爆发 | 焚风 |
| 疾行 | 112 速 | 三连发覆盖 | 泥沼 |

**元素是加速器，不是钥匙。** 没有也能打，只是会漏。

### 升级（每关结束选 1 个，四选一，全部改行为）

穿透 / 三连发 / 蓄力箭（无视虚化）/ 长弓。

---

## 五、机器验证过的难度

`node test/sim.js` 用三种策略各跑一遍，结果**完全确定**（零随机，同样操作同样结果）：

| 策略 | 结果 |
|---|---|
| 会用元素 | **通关，剩 17 血** |
| 从不合成 | 打到第 4 关，**倒在疾行那一波** |
| 只会选升级 | 同上 |

## 六、调参

文件顶部几个旋钮：

| 常量 | 作用 |
|---|---|
| `DIFF` | **全局难度**，直接乘怪物血量（现在是 1.0，调 0.8 变简单，1.3 变难） |
| `ELEM_CAP` | 元素上限（4） |
| `SHOT_SPEED` | 箭速（1250），调慢会开始打空 |
| `TYPES` | 每种怪的血/速/破墙伤害/掉落 |
| `FUSIONS` | 三融合的配方与时长 |
| `LEVELS` | 出兵表 `seq(开始秒, 路线, 怪种, 数量, 间隔)` + `hpMul` + `supply` |
| `UPGRADES` | 升级 |

调试参数：

```
?autostart=1&level=2&ff=10&wall=50&fx=scorch&craft=light
```

## 七、已知局限

- 三路只体现"同一时刻只能打一个目标"，还没有"必须放弃某一路"的硬约束（需要转身延迟）
- 没有音效
- "带多少元素走" 因为掉落充足，决策强度被削弱了——这是这次改动的代价
- 第 4 关（疾行）是一个明显的坎：不会用泥沼基本过不去

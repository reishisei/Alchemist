# 炼金法师（原型集）

一个「**合成 → 成长 → 战斗**」的游戏原型，以及它的完整设计文档。

> 你是法师学徒，选一个元素系。战斗赚钱 → 用钱买别的系元素 → 炼出新元素和技能 → 技能让你打得更远。
> 越往上走，能带的东西**越少但越强**，最后只有 2–3 个技能，和 3 个合成位去结「禁咒」。

**没有构建、没有依赖、没有服务器。** 双击 HTML 就能玩。

## 玩

直接用浏览器打开：

- `alchemy/index.html` —— 炼金台：22 种元素、19 条配方、选系、本系 ∞、元素上限（没有 100%）、仓库、图鉴
- `castle-guard/index.html` —— 守墙三路：5 关、三路、掉元素、撞墙即破

或者打开 `index.html` 从入口页进。

---

## 验

两个脚本覆盖了已经踩过的坑，改任何东西前先跑：

```bash
node alchemy/test/sim.mjs      # 配方自洽 / 层级 / 可达 / 选系 / 元素上限 / 保底 / 升阶只看技能
node castle-guard/test/sim.js  # 三种策略跑完整局，验证难度曲线（零随机，可复现）
```

预期输出：

```
PASS  元素 22 · 配方 19 条 · 全部可达 · 选系/上限/保底
[通关全部] 剩余城墙 17  击杀 44
```

## 设计上唯一不能丢的两条

1. **不写「禁止」，写「诱惑」**——本系给 50、外系给 35，叠加才到 85；元素永远没有 100%，100% 只留给技能。
2. **用户讨厌的是赌博，不是难度**——任何"随机决定成败"的地方，都要有保底或补偿。

详见 [游戏设计文档.md](游戏设计文档.md)。

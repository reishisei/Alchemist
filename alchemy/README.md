# 炼金台 · 元素树（v3）

单文件、零依赖。双击 `index.html`。

这一版**去掉了技能**，只做元素。目标是先把"元素怎么长出来"理清楚。

## 一、元素树

### 基础（4）
火　水　风　土

### 一级（基础 × 基础，6 条全有）
| 组合 | 产物 |
|---|---|
| 水 + 火 | 电 |
| 火 + 风 | 爆 |
| 火 + 土 | 金属 |
| 水 + 风 | 冰 |
| 水 + 土 | 毒 |
| 风 + 土 | 沙 |

### 二级（一级 × 基础）
| 组合 | 产物 |
|---|---|
| 火 + 冰 | **水（还原）** |
| 火 + 沙 | 玻璃 |
| 水 + 沙 | 泥 |
| 火 + 金属 | 熔金 |

| 火 + 毒 | 烟 |
| 土 + 电 | 磁 |

### 三级（一级 × 一级）
| 组合 | 产物 |
|---|---|
| 电 + 冰 | 霜雷 |
| 电 + 金属 | 磁暴 |
| 毒 + 金属 | 蚀钢 |
| 沙 + 金属 | 砂铁 |

**共 22 种元素 / 19 条配方。**

> 只有这 19 条有结果，其余搭配一律"没有反应"——这是有意的，不是所有元素都能配对。

## 二、还原

`火 + 冰 = 水`：产物是基础元素，不产生新发现，但能把高阶元素换回基础材料。

界面上标成"还原"，成功率固定 75%，不走熟练度。

---

## 三、其他规则

- **刷新 +4** 进仓库，仓库容量 24，右键丢弃
- **合成消耗两个材料**，成功产物落回原位；**失败也消耗**（-2）
- **熟练度**：第一次 50%，**成功 +25%**（3 次掌握），**失败 +4%**（不让你卡死）
- **掌握** = 必定成功 + 进入随机池（刷新能直接抽到）
- **阶级**按"新发现的元素种数"算：
  - 见习 0–2 → 只能抽基础
  - 中级 3–6 → 能抽一级
  - 高级 7+ → 能抽二级三级

## 四、验证

```bash
node test/sim.mjs
```

验六件事：配方自洽、层级规则（基础×基础→一级 / 一级×基础→二级 / 一级×一级→三级）、
从基础出发能否长成整棵树、消耗契约（失败 -2、成功 -2+1）、熟练度到 100%、阶级判定。

```
PASS  元素 22 · 配方 19 条 · 全部可达
节奏：约 400 次操作 → 发现 22/22 种（约 6–8 分钟）
```

### 为什么不是"成功 +10%"

22 个元素的树比原来的 15 个深得多，实测四组参数（每组跑 3 次）：

| 每次成功 | 失败补偿 | 平均操作数 | 波动范围 |
|---|---|---|---|
| +10% | 0 | **1035** | 667–1223 |
| +10% | +4% | 701 | 417–890 |
| +25% | 0 | 519 | 339–617 |
| **+25%** | **+4%** | **406** | 195–513 |

+10% 那组最坏要 1200 多次操作（20 分钟），主要卡在"要凑两个一级元素同时在场"。
现在默认是 +25 / +4；想回到原来的手感，把 `MAST_GAIN` 改回 10、`MAST_ON_FAIL` 改回 0。

## 五、已知问题

- 全解锁约 6–8 分钟（400 次操作）
- **二级/三级是终点**：它们不能再参与任何配方，目前只是图鉴收藏
- 还原只有 1 条，够不够多要看手感
- 技能已全部移除，等元素定稿再加回来

## 六、加配方的方法

`index.html` 里的 `RECIPES`，加一行：

```js
'earth+water': { element:'poison' },   // 键按字母序
```

加 `reduce:true` 就是还原。

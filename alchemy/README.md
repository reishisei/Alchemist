# 炼金台 · 元素树（v4）

单文件、零依赖。双击 `index.html`。

v4 在 v3 的元素树上加了**选系 + 本系无限 + 熟练度上限 + 连败保底**，
把"免费的路线有天花板"从文档变成了能玩到的规则。技能仍然没有。

## 二、还原

`火 + 冰 = 水`：产物是基础元素，不产生新发现，但能把高阶元素换回基础材料。

界面上标成"还原"，成功率固定 75%，不走熟练度。

---

## 三、选系与本系无限

开局四选一（火 / 水 / 风 / 土）。

- **本系基础元素无限供应**：仓库最左边那个 `∞` 圈，不占 24 格、不用刷新、丢不掉
- 刷新只发**外系**素材（本系不再浪费格子）
- 本系元素在仓库里显示成带 `∞` 角的圆，合成时照常占一个台面位

## 四、熟练度天花板（v4 核心）

元素合成按用料叠上限：本系给 50 的底子，外系给 35 的底子，两个叠起来才是 85。

| 用料 | 上限 |
|---|---|
| 本系 + 本系 | **50%** |
| 本系 + 外系 | **85%**（50 + 35） |
| 外系 + 外系 | **35%** |

- **同类不叠加**：两个本系还是 50，两个外系还是 35
- **元素合成永远到不了 100%**：没有"掌握"，练到上限就停住，成功率锁在上限
- **100% 只属于技能**：技能练满 100% 才叫掌握，升阶也只数掌握的技能
  （技能层还没做，所以这一版停在见习）
- 选系决定哪些配方是 85：例如火系炼「电」（火+水）85%，炼「冰」（水+风）只有 35%
- 选系页会写每个系「带本系 85%」和「纯外系 35%」各多少条

### 不做纯赌博

**连续失败 2 次后，下一次必定成功**（`PITY_N = 2`）。
85% 和 35% 的配方都靠这个保底，也符合设计文档里"随机处必须给保底"那条。

## 五、其他规则

- **刷新 +4** 进仓库，仓库容量 24，右键丢弃
- **合成消耗两个材料**，成功产物落回原位；**失败也消耗**（-2）
- **熟练度**：第一次 50%（纯外系从 35 起），**成功 +25%**，**失败 +4%**，到上限就停
- **没有元素掌握**：元素永远到不了 100%，也不进随机池（池子里只有基础元素）
- **升阶**：掌握 100% 的技能（技能层未实现，所以现在升不了阶）
  - 素材等级锁已临时移除，否则 demo 会卡在见习；等技能层接上再恢复

## 六、验证

```bash
node test/sim.mjs
```

验这些：配方自洽、层级规则、整树可达、选系、本系 ∞ 的消耗契约、
熟练度上限（50/85/35，元素永远不到 100%）、连败保底（85% 和 35% 都测）、
还原、升阶只看技能、以及一局完整流程。

```
PASS  元素 22 · 配方 19 条 · 全部可达 · 选系/上限/保底
节奏：约 270 次操作 → 发现 22/22 种
```

> 比 v3 的 400 次快，主要因为本系 ∞ 省掉了刷本系基础元素的动作；
> 比上一版慢，是因为随机池不再发"掌握过的元素"，三阶材料得现做，纯外系又只有 35%。

### 为什么不是"成功 +10%"

22 个元素的树比原来的 15 个深得多，实测四组参数（每组跑 3 次）：

| 每次成功 | 失败补偿 | 平均操作数 | 波动范围 |
|---|---|---|---|
| +10% | 0 | **1035** | 667–1223 |
| +10% | +4% | 701 | 417–890 |
| +25% | 0 | 519 | 339–617 |
| **+25%** | **+4%** | **406** | 195–513 |

+10% 那组最坏要 1200 多次操作（20 分钟），主要卡在"要凑两个一级元素同时在场"。
现在默认是 +25 / +4；想回到原来的手感，把 `MAST_GAIN` 改回 10、`MAST_ON_FAIL` 改回 0。

## 七、已知问题

- 全解锁约 270 次操作
- 纯外系只有 35%，而三阶元素大多要纯外系配方 —— 手感偏硬，等技能/道具来调
- **二级/三级是终点**：它们不能再参与任何配方，目前只是图鉴收藏
- 还原只有 1 条，够不够多要看手感
- 选系后不能改，只能"重开"（故意的，但不排除以后给一次"换系"）
- 升阶、技能、金币 / 商店都还没有

## 八、加配方的方法

`index.html` 里的 `RECIPES`，加一行：

```js
'earth+water': { element:'poison' },   // 键按字母序
```

加 `reduce:true` 就是还原。

# 炼金台 · 元素树（v4）

单文件、零依赖。双击 `index.html`。

v4 在 v3 的元素树上加了**选系 + 本系无限 + 熟练度上限 + 连败保底**，
把"免费的路线有天花板"从文档变成了能玩到的规则。技能仍然没有。

---

## 一、元素树

### 基础（4）
火　水　风　土

### 一级（基础 × 基础，6 条全有）
| 组合 | 产物 |
|---|---|
| 水 + 火 | 电 |
| 火 + 风 | 爆 |
| 火 + 土 | 金属 |
| 水 + 风 | 冰 |
| 水 + 土 | 毒 |
| 风 + 土 | 沙 |

### 二级（一级 × 基础）
| 组合 | 产物 |
|---|---|
| 火 + 冰 | **水（还原）** |
| 火 + 沙 | 玻璃 |
| 水 + 沙 | 泥 |
| 火 + 金属 | 熔金 |
| 水 + 金属 | 锈 |
| 火 + 毒 | 烟 |
| 土 + 电 | 磁 |
| 水 + 电 | 汽 |

### 三级（一级 × 一级）
| 组合 | 产物 |
|---|---|
| 电 + 冰 | 霜雷 |
| 电 + 金属 | 磁暴 |
| 毒 + 金属 | 蚀钢 |
| 沙 + 金属 | 砂铁 |
| 爆 + 冰 | 霜爆 |

**共 22 种元素 / 19 条配方。**

> 只有这 19 条有结果，其余搭配一律"没有反应"——这是有意的，不是所有元素都能配对。

---

## 二、还原

`火 + 冰 = 水`：产物是基础元素，不产生新发现，但能把高阶元素换回基础材料。

界面上标成"还原"，成功率固定 75%，不走熟练度。

---

## 三、选系与本系无限

开局四选一（火 / 水 / 风 / 土）。

- **本系基础元素无限供应**：仓库最左边那个 `∞` 圈，不占 24 格、不用刷新、丢不掉
- 刷新只发**外系**素材（本系不再浪费格子）
- 本系元素在仓库里显示成带 `∞` 角的圆，合成时照常占一个台面位

## 四、熟练度天花板（v4 核心）

判定只看**这对素材从哪来**，不看元素种类：

| 用料 | 上限 | 能否掌握 |
|---|---|---|
| 本系 + 本系（两份都免费） | **50%** | 不能 |
| 本系 + 外系 | **85%** | 不能 |
| 外系 + 外系 | **100%** | **能（必成 + 进随机池）** |

- 只有从 `∞` 槽拿的才算"本系"；仓库里的同种元素（如果以后商店能买到）算外系
- 每个产物只有一条配方，所以**选系决定了哪些元素这一局能练满**：
  火/水各 12 种、土 14 种、风 15 种（共 18 种产物），选系页会直接写出来
- 85% 封顶的配方不会进随机池 —— 它就是你这一局的"半成品"，便宜但永远差一口气
- `本系 + 本系 = 50%` 这条规则已经实现，但现在没有"同元素配方"，暂时触发不到；
  等以后加 `火 + 火` 这类配方时会自动生效

### 不做纯赌博

**连续失败 2 次后，下一次必定成功**（`PITY_N = 2`）。
85% 封顶的配方靠这个不至于卡死，也符合设计文档里"随机处必须给保底"那条。

## 五、其他规则

- **刷新 +4** 进仓库，仓库容量 24，右键丢弃
- **合成消耗两个材料**，成功产物落回原位；**失败也消耗**（-2）
- **熟练度**：第一次 50%，**成功 +25%**，**失败 +4%**
- **掌握** = 100% 且必定成功 + 进入随机池
- **阶级**按"新发现的元素种数"算（选系不改这个）：
  - 见习 0–2 → 只能抽基础
  - 中级 3–6 → 能抽一级
  - 高级 7+ → 能抽二级三级

## 六、验证

```bash
node test/sim.mjs
```

验十件事：配方自洽、层级规则、整树可达、选系（不给材料 / 本系不进池）、
本系 ∞ 的消耗契约（只扣外系、满仓不溢出）、熟练度上限（50/85/100）、
连败保底、还原、阶级、以及一局完整流程。

```
PASS  元素 22 · 配方 19 条 · 全部可达 · 选系/上限/保底
节奏：约 110 次操作 → 发现 22/22 种，掌握 3（火系）
```

> 比 v3 的 400 次快很多，主要因为本系 ∞ 省掉了刷本系基础元素的动作。

### 为什么不是"成功 +10%"

22 个元素的树比原来的 15 个深得多，实测四组参数（每组跑 3 次）：

| 每次成功 | 失败补偿 | 平均操作数 | 波动范围 |
|---|---|---|---|
| +10% | 0 | **1035** | 667–1223 |
| +10% | +4% | 701 | 417–890 |
| +25% | 0 | 519 | 339–617 |
| **+25%** | **+4%** | **406** | 195–513 |

+10% 那组最坏要 1200 多次操作（20 分钟），主要卡在"要凑两个一级元素同时在场"。
现在默认是 +25 / +4；想回到原来的手感，把 `MAST_GAIN` 改回 10、`MAST_ON_FAIL` 改回 0。

## 七、已知问题

- 全解锁约 110 次操作（比以前快，但上限规则让 6 种元素永远 85%）
- **二级/三级是终点**：它们不能再参与任何配方，目前只是图鉴收藏
- 还原只有 1 条，够不够多要看手感
- 选系后不能改，只能"重开"（故意的，但不排除以后给一次"换系"）
- 金币 / 商店 / 技能都还没有

## 八、加配方的方法

`index.html` 里的 `RECIPES`，加一行：

```js
'earth+water': { element:'poison' },   // 键按字母序
```

加 `reduce:true` 就是还原。
